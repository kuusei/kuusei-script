# Steam 国区参考定价辅助工具

在 Steam 库存或市场详情页打开物品的出售弹窗。价格栏下方显示国区最高五档求购、最低五档在售和每档数量。可以手填国区目标价并点击「换算填入」，也可以点国区最低价和低 ¥0.01 两个快捷按钮。

Steam 批量出售页在每种物品下方提供「国区参考价」。页面只有一种物品时会默认展开，有多种时可展开对应物品进行查询和填价。

脚本自动识别印度卢比或乌克兰格里夫纳钱包，按 0.3% 的汇率余量和 Steam 手续费换算，将收款向下取到两位小数并填入「您收款」。

「买家支付」由 Steam 更新，可能将相近的收款金额显示为同一档售价。乌克兰格里夫纳的最低收款金额由 Steam 钱包数据提供。Steam 使用自己的汇率，实际国区显示价以上架结果为准。
