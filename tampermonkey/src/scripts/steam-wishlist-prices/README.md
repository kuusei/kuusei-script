# Steam 愿望单区域比价

对比愿望单游戏和 DLC 的各区价格，显示人民币换算、折扣、截止时间和可送礼提示。可选接入 ITAD 本区史低。

## 使用

1. 在油猴中安装脚本，打开 Steam 愿望单，点击「区域比价」。
2. 选择账户区和比价区。愿望单 ≤4000 项最多选 9 区，超过 4000 项最多选 5 区，均含账户区。
3. 使用搜索、筛选和排序查看结果。默认按相对账户区差价从低到高排序。

## 价格

- 各区价格来自对应区域的 Steam 愿望单，人民币金额按当前汇率换算。
- 绿色表示最低价，浅蓝表示接近最低价。
- 更便宜的捆绑包价格单独显示；不参与游戏自身的史低判断。
- 「可送礼」按相对账户区差价估算，可选择严谨 10% 或宽松 15%；实际能否赠送以 Steam 为准。

## 史低

打开「史低设置」，填写在 [ITAD 应用管理](https://isthereanydeal.com/apps/)获得的 API Key；留空保存可停用。

- 仅查询账户区的 Steam 历史最低价，其他区不标记；缺少记录时显示暂无史低数据。
- 现价达到历史最低价时标记「史低」；低于 ITAD 记录，或 ITAD 确认新低价时标记「新史低」。
- ITAD 识别可能滞后，部分新史低会仅标为史低。
- 配置后才显示「史低 / 新史低」筛选。这两项只筛选本区正在打折的游戏，史低包含新史低；与「折扣」互斥。

## 愿望单标签

读取 Steam 自定义愿望单标签。点击游戏上的标签可快速筛选，工具栏支持搜索、多选、排除和未分类；包含匹配任意已选标签，命中任意排除标签则隐藏，与其他筛选取交集。再次点击可取消，同一标签的包含与排除互斥。

自己的愿望单可添加、移除、创建标签，以及在「管理标签」中重命名，保存直接同步到 Steam。标签刷新和编辑不会重新请求价格；他人的标签仅在分享权限允许时展示，不能编辑。

编辑弹窗按 Steam 类别界面布局，搜索和添加共用一个输入框；输入新名称后按 Enter 或点击添加，再点「完成」保存。

## 导出截图

点击右下角的导出图标，选择手机版（960px）或 PC 版（2560px），可选择附带插件名称、作者和安装链接。以 2 倍分辨率导出当前筛选、排序和比价区域下的全部结果，保存为压缩 JPG；单张接近 65000px 高时按游戏分图，分别下载。每张图按内容实际高度一次渲染，不做内部切块或拼接。超过 50 款游戏时提示可能耗时较长。封面集中并行读取并复用缓存，进度按游戏数量显示；控制台记录封面读取、渲染和 JPG 压缩耗时。

## 缓存

Steam 价格缓存 1 小时。史低记录持久保存，切换账户区后清除；现价高于或等于已保存史低时不再请求 ITAD。已确认的新史低标记在价格、币种和折扣截止时间不变时保留。

自己的愿望单标签缓存 5 分钟，重复打开时复用；愿望单重新拉取时更新标签，编辑后同步更新缓存。标签菜单中的「刷新」立即从 Steam 重读；读取失败时保留旧标签，暂时不能编辑。他人分享的标签不缓存。
