# Steam 挂刀比例计算器

在 CS2 新版社区市场的物品详情页，给买卖盘补充前十档、堆积数量、税后人民币、挂刀比例和总金额。

- 只在 CS2 市场详情页工作，需要已登录的 Steam 钱包。
- 按钱包币种的最小单位、步长和手续费，从买家出价反推卖家税后到手价。
- 非人民币钱包会自动读取汇率并换成人民币；人民币钱包按 1:1。
- 填写这批货的人民币总价和数量后，每一档显示单个成本相对税后到手价的比例，以及按该数量估算的税后总额。
- 页面买卖档不足十档时，用订单深度补齐，并改写原来的「更多」行。
- 手动刷新至少间隔 10 秒。盘口和计算结果不一致时，会自动再拉一次深度。

打开某个 CS2 物品的社区市场页面，先在 Steam 页面里选中具体物品。表格上方会出现「挂刀比例」。把购买总价和数量填进去即可。
