# Steam 评测语言增强

在 Steam 商店游戏页面的评测区顶部显示各语言的评论数、好评数、差评数、占比和好评率。

- Steam 风格的紧凑表格，默认显示评论最多的 8 种语言，可展开全部。
- 点击「评论数」「好评数」「差评数」「好评率」排序。
- 好评与差评采用 Steam 原生蓝、红色，每行背景铺满，按该语言自身的好评率和差评率划分。
- 点击语言名，在新标签页查看该语言的社区评测。
- 使用 Steam 商店评分口径，排除题外评测；付费游戏不包含 Key 激活等非 Steam 购买评测。
- 额外展示「全部语言（全部购买方式）」汇总，两条汇总与语言明细隔开，不参与背景堆积或语言占比的计算。
- 复用页面数据，不增加请求；缺少数据时最多请求一次商店页，点击刷新也只请求一次，缓存 1 小时。
- 未单列的部分合并为「其他语言」，总计与语言明细采用同一口径。无需 API Key。

安装脚本后刷新 Steam 游戏商店页，在「顾客评测」区域顶部查看「各语言评测」表格。
